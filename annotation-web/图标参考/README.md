# 题目图标参考

按 `<任务>/<类型>/<题目>/` 保存固定参考图及一份 `参考.json`，网页根据当前队列分类展示。不提供参考图编辑功能。

```json
{"说明":"该题目的范围和容易混淆的物品", "图标":[{"名称":"物品名", "图片":"物品名.png", "来源":"https://原始资料页", "图片来源":"https://原图地址"}]}
```

只保存实际查阅且核对过的参考图，注明来源；不得把其它游戏或手游图片冒充口袋版对应图标。参考资料与 AI 建议帮助用户审核，不是正式测试真值。图片通过 Git LFS 管理。

参考列表只展示符合本题范围的正例；其它等级、功效和武器类别不能混入，排除对照及旧资料归档到 `debug-runs/`。先核对名称、等级、功效或装备类别，再决定入选，不能由“药品”“烹饪”“武器”等大类直接推出答案。

参考图鉴覆盖题目允许的完整物品范围，包括各个等级，不只保存当前输入已匹配的图标；题目限定等级时按限定筛选。资料未覆盖的等级或物品须注明缺口，不声称已收全。

交付前须从最终 `建议.json` 的原图坐标逐框裁图复核，并说明每框的具体物品及入选依据；不能只检查编号长图、文件数量或测试是否通过。无法命名或确认类别的图标须注明疑点，不冒充已核实答案。

AI 处理每个题目时：先查网上资料和图标，随后完整检查该题目全部未完成输入，写入各输入的 `建议.json` 和简短 `建议说明.md`。只写有依据的候选；不修改原图、`答案.json`、已完成队列或正式测试库。无法确定的物品就近说明，不能悄悄当作已确认反例。
