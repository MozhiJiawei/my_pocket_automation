# 公共设备能力

`navigation.lua` 负责已保存角色名单核对、选择、主页身份验证及安全返回主页。角色特征和授权放在仓库外；这里只维护通用页面特征。选择名字而非卡片序号，每次切换后核对主页身份。

`screen.lua` 管理实际坐标方向；`detector.lua` 使用设备找色接口；`device.lua` 在输入前重新验证目标。常规操作默认不截图；错误保留现场。任务资源随任务维护，公共模块不承载任务答案。

`find_items.lua` 为抓鬼与师门共用的只读物品搜索，保持单帧、页面校验、多点找色和点击偏移；抓鬼取首个匹配，师门枚举当前画面的匹配位置。方向特征离线生成，公共搜索不点击、不翻页、不承担任务重试。

名单扫描有页数上限，名字与卡片须一一对应。出现未知角色、缺失配置、无法安全离开的现场时保存证据并停止，不宣称遍历完成。
