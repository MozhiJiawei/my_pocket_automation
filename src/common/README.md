# 公共设备能力

`navigation.lua` 负责已保存角色名单核对、选择、主页身份验证及安全返回主页。角色特征和授权放在仓库外；这里只维护通用页面特征。选择名字而非卡片序号，每次切换后核对主页身份。

返回主页前识别并关闭已校准的“突发事件”浮层，收起展开的聊天栏，确认浮层消失后再导航；未知弹窗仍停止。`device.tap` 支持业务前置条件回调，在定位前与最终点击前分别核对，防止留证期间状态改变后执行旧动作。

`screen.lua` 管理实际坐标方向；`detector.lua` 使用设备找色接口；`device.lua` 在输入前重新验证目标，点击统一使用手指1并按压50毫秒，与滑动共用固定触点。常规操作默认不截图；错误保留现场。任务资源随任务维护，公共模块不承载任务答案。

`application.lua` 管理互通版启动，核验进程与已知入口、确认页、主页或角色列表。正式每日任务先由 Lua 关闭现有进程并验证退出，再启动游戏。启动请求至多一次，120秒未识别即保存失败现场，成功只留一张入口验收图。点击、登录及任务推进由各自流程处理。

口袋入口兼容新旧右侧菜单布局，在右下菜单区域识别按钮内部特征，允许小幅位置变化。入口连续三次可见且中央加载转圈消失才允许点击，留证后再次核验加载状态。入口、确认和竖屏过渡采用实际时间截止。点击入口后核对确认框或已就绪的竖屏页面，若超时仍停在入口则单独记录页面未转换并留证。已有主页、角色选择页和可安全返回的任务页继续复用，已发送的入口或确认点击不重复发送，最终仍须核验竖屏主页与角色身份。

`find_items.lua` 为抓鬼与师门共用的只读物品搜索，保持单帧、页面校验、多点找色和点击偏移；抓鬼取首个匹配，师门枚举当前画面的匹配位置。方向特征离线生成，公共搜索不点击、不翻页、不承担任务重试。

`list_navigation.lua` 统一任务列表与副本横向列表的遍历。业务模块只提供当前列表校验、目标特征或明确完成状态，以及可视区域；师门入口、抓鬼入口、副本选择、师门与抓鬼完成卡片查找、葫芦调测前置检查共用此模块。先等可视区域连续三帧稳定再识别；正向搜索、识别重复画面边界后反向搜索，反向上限覆盖正向行程和初始位置另一侧。默认最多8步正向、16步反向；画面未变化时，每步最多换3个起点验证拖拽，避免把卡片间空隙造成的无效拖拽当成边界。页面改变或稳定等待超时即保存现场停止。激活前重新校验列表与目标，点击后由业务模块验证状态；目标缺失、卡片消失和滚动到边界均不能证明任务完成。

名单扫描有页数上限，名字与卡片须一一对应。普通头像角标和绿色“当前”丝带按纵向位置合并扫描，避免当前标记遮住卡片特征；两者仅提供卡片锚点，角色名字仍须独立且唯一匹配。出现未知角色、缺失配置、无法安全离开的现场时保存证据并停止，不宣称遍历完成。

`src/progress.lua` 保存按角色隔离的运行期进度，并通过 `src/completion.lua` 读写每日完成布尔状态。持久化记录仅包含业务日、角色别名、主页身份绑定及师门、抓鬼、两个副本、开葫芦的完成标志；任务内部进度、次数和重试不落盘。当前运行已核验状态直接复用，未完成任务从游戏页面恢复；旧日志与调试截图不参与业务决策。
