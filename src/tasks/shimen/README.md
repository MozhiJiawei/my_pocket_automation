# 师门

`task.lua` 按页面状态持续推进已安排的师门任务，最终以同角色当天的明确完成卡片验收。接取和交付均验证页面变化，不读取任务数量，不设置费用预算。已有任务保留识别重试与恢复状态；`enter` 只观察入口，`advance` 推进当前步骤，`complete/daily` 持续运行至完成卡片或待处理现场。

结束对话关闭后，完成的师门卡片可能移到列表下方。Lua 使用公共列表遍历双向查找，同时匹配师门标题与“已完成”印章，核对角色和业务日期后记录 `completion_card_verified`。卡片缺失或小游戏退出不能证明整项完成。未知过渡页最多只读等待5秒。途中剧情对话按已核验的对话框特征推进，每页须验证文字或页面变化，最多12步；额外切磋邀请通过“放弃”关闭后继续师门。

启动时根据游戏页面建立运行期账本。已有完成卡片可直接验收，不补造此前的执行或费用历史。

已有任务从当前对话、寻物、拼图或战斗页面恢复，不读取旧日期记录。交付后核对角色和空闲页面，再继续任务。获得葫芦提示只等待自动关闭。

本次运行内每项任务的寻物最多免费重试3次（加首次共4次尝试）；`find_attempts` 仅保留在内存里。重启后从当前页面重新建立运行期状态。失败保存截图并进入标注流程，达到重试上限保留现场。小游戏成功后继续交付，部分交付只记推进状态，最终仍须看到完成卡片。

拼图由 Lua 先尝试旧特征，自动识别唯一题型；不能识别、匹配歧义、交换失败或退出后出现失败重试提示时保存完整原图并停止。电脑端仅收集证据，队列交接不操作设备。未知页面与操作后未达预期状态同样停止并保留现场。

`puzzle.lua` 在已有任务推进中使用历史资源，可自动核对唯一题型或明确指定题型。`assets/legacy_puzzles.lua` 由 `scripts/perception/import-shimen-puzzles.py` 从 `参考代码/pt.lua` 导入28类、112块多点颜色特征，离线按1.8倍展开；运行时不缩放、不调整阈值、不遍历缩放策略，也不使用旧点击坐标。每块特征所有点必须落在同一个当前格子，出现重复匹配或不足三块匹配时停止；恰有三块唯一匹配时，第四块按剩余格确定。最多三次交换，每次核对目标块归位。

`assets/reviewed_puzzles.json` 保存已确认截图校准的特征覆盖，也支持历史资源未命名的新题型；新题型必须具备四块确认特征，由同一导入工具生成到发布资源中。当前资源共31类、124块，新增地狱战神、雨师与骨精灵使用人类确认的原图与排列。老虎第1块使用格内采样点，替换旧特征中落在当前格子下边框的两个点；天将、天兵、螃蟹、虾兵、白熊四块使用已确认原图内的固定采样点，螃蟹资源对应游戏中的蟹将。正式拼图真值在 `testdata/师门/拼图/`；评测临时交换四块位置，检查全部排列，运行时仍直接匹配固定特征。校准后的四块直接匹配覆盖正式截图及其位置排列；设备验证范围以实际运行证据为准。

```powershell
python scripts/device/run-daily.py --device <设备> --task shimen --mode run --step advance --account current --shimen-puzzle-family 老虎
```

此参数只操作当前可见拼图，不免费重开、不接新任务、不提交师门任务完成。小游戏退出后仍需核对后续战斗或抓怪成功画面；任务完成须另行验证交付、角色与次数。老虎、天将、天兵、螃蟹、虾兵、白熊、地狱战神、雨师、骨精灵已完成拼图设备验证，其余历史图案只有资源导入，尚未逐类验证；所有实际操作均由 Lua 状态机执行。

执行时只搜索本轮尚需的答案数量，支持跨滚动页选择；点击前在原匹配锚点附近重验证完整特征，滚动后等待画面稳定。未找齐时退出题框判为失败。设备日志中的完成结果须结合实际“寻找成功”画面核验，不能以题框消失代替业务证据。流程控件仅覆盖已采集页面；免费重试分支及未见题型尚未全部设备验证，未知页面停止；禁止电脑端代操作。

正式寻物输入在 `testdata/师门/寻物/`。资源从用户确认的正例校准，方向展开与去重在电脑端完成；全量数据用于校准，离线通过只证明已标样本覆盖，不证明未见图标或设备业务完成。未知题目不跨类别兜底。

```powershell
python scripts/perception/calibrate-reviewed-items.py --task shimen
python scripts/perception/compile-find-catalog.py --task shimen
python scripts/perception/evaluate.py --task shimen
python scripts/test.py --group 师门
```

校准中间文件保存在 `.tmp/`，正式资源只有题干与物品特征。题目、原图和真值沿用公共读取、原图映射、增强和评分；不读取标注队列或网上参考图。寻物失败及未确认拼图进入标注器，由 AGENT 先完成 AI 标注，再提交人类确认，确认后固化、校准和回归；拼图可保留会话中的明确确认依据。寻物失败时 Lua 在本次运行的免费重试上限内先重试绕过，等待人类标注。流程截图由 AGENT 自主核对并直接固化，不进入待标注队列。

只读观察入口为 `scripts/device/inspect-device.py`；采集所需的页面操作必须通过 Lua 状态机。识别题失败原图按任务和题目进入标注器，流程失败现场由 AGENT 自主处理。已有任务可用 `run-daily.py --mode run --task shimen --step advance --account current --shimen-needed 2` 执行设备识物，调试时增加 `--routine-screenshots --verbose-logs` 保留点击前后画面。采集过程和评测报告保存在 `debug-runs/`。
