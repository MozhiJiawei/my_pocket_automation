# 师门

`task.lua` 使用页面状态循环、验证后操作、持久化账本及有界等待。`pages.lua` 接入任务列表、师门卡片、前往、寻物地点选择、整理库存、抓怪准备、示威、领教、交付、对话下一步及领取页的次数读取。`enter` 核对角色后仅打开师门页，不接取任务或写入进度。已有任务须有账本才可恢复；新业务日核对角色、空闲页面及零次数后可建立当天账本。`complete` 在交付后核对角色、未进行任务状态和账本次数，再预留下一次任务并领取，直到20次或遇到无法推进的现场停止。`find.lua` 的 `read()` 提供题目识别和当前画面的多答案定位，`solve()` 默认寻找两个答案，调用 `common.find_items`；识别资源跟随本任务，运行时不变换图像或特征。

第20次交付后可出现独立结束对话，关闭后师门卡片移到列表下方。Lua 最多滚动4次查找，同时匹配灰色师门标题与“已完成”印章；只有核对角色、重新观察完成卡片，并确认当天账本已接取20次且已完成19或20次，才写入最终完成状态。入口缺失、结束对话或20/20次数不能单独证明完成。页面切换中的未知状态最多只读等待5秒，仍未知则保存现场停止。

跨日保留任务使用单角色 `complete` 的 `--shimen-resume-date <旧账本日期>`，日期须早于本轮业务日。只有旧账本持有活动任务、当前活动页面可识别且次数清零时才续做；保留这项任务的识物尝试次数，不复制旧日的完成次数或精力预留到当天。交付后核对角色与零次数，再接取当天第一项；旧任务完成后标记旧账本已移交，防止重新作为活动任务接管。自动关闭的葫芦获得提示最多等待5秒，不点击开启按钮。

每项任务的寻物最多免费重试3次（加首次共4次尝试）；执行前保存 `find_attempts`，重启不清零。失败保存截图，电脑端仅收集证据并交接标注队列；第4次仍失败保存现场停止。只在已记录任务的免费重试对话续试，不重新接取。题框退出不记为任务完成；必须核对角色、未进行任务状态及与账本一致的次数，才能提交完成记录。N/20 在领取时增加，不能单独作为完成证据。

拼图由 Lua 先尝试旧特征，自动识别唯一题型；不能识别、匹配歧义、交换失败或退出后出现失败重试提示时保存完整原图并停止。电脑端仅收集证据，队列交接不操作设备。未知页面与操作后未达预期状态同样停止并保留现场。

`puzzle.lua` 在已有任务推进中使用历史资源，可自动核对唯一题型或明确指定题型。`assets/legacy_puzzles.lua` 由 `scripts/perception/import-shimen-puzzles.py` 从 `参考代码/pt.lua` 导入28类、112块多点颜色特征，离线按1.8倍展开；运行时不缩放、不调整阈值、不遍历缩放策略，也不使用旧点击坐标。每块特征所有点必须落在同一个当前格子，出现重复匹配或不足三块匹配时停止；恰有三块唯一匹配时，第四块按剩余格确定。最多三次交换，每次核对目标块归位。

`assets/reviewed_puzzles.json` 保存已确认截图校准的特征覆盖，由同一导入工具生成到发布资源中。老虎第1块使用格内采样点，替换旧特征中落在当前格子下边框的两个点；天将、天兵、螃蟹、虾兵、白熊四块使用已确认原图内的固定采样点，螃蟹资源对应游戏中的蟹将。正式拼图真值在 `testdata/师门/拼图/`；评测临时交换四块位置，检查全部排列，运行时仍直接匹配固定特征。校准后的四块直接匹配覆盖正式截图及其位置排列；设备验证范围以实际运行证据为准。

```powershell
python scripts/device/run-daily.py --device <设备> --task shimen --mode run --step advance --account current --shimen-puzzle-family 老虎
```

此参数只操作已记录的当前拼图，不免费重开、不接新任务、不提交师门任务完成。小游戏退出后仍需核对后续战斗或抓怪成功画面；任务完成须另行验证交付、角色与次数。老虎、天将、天兵、螃蟹、虾兵、白熊已完成拼图设备验证，其余历史图案只有资源导入，尚未逐类验证；所有实际操作均由 Lua 状态机执行。

执行时只搜索本轮尚需的答案数量，支持跨滚动页选择；点击前在原匹配锚点附近重验证完整特征，滚动后等待画面稳定。未找齐时退出题框判为失败。设备日志中的完成结果须结合实际“寻找成功”画面核验，不能以题框消失代替业务证据。流程控件仅覆盖已采集页面；免费重试分支及未见题型尚未全部设备验证，未知页面停止；禁止电脑端代操作。

正式寻物输入在 `testdata/师门/寻物/`。资源从用户确认的正例校准，方向展开与去重在电脑端完成；全量数据用于校准，离线通过只证明已标样本覆盖，不证明未见图标或设备业务完成。未知题目不跨类别兜底。

```powershell
python scripts/perception/calibrate-reviewed-items.py --task shimen
python scripts/perception/compile-find-catalog.py --task shimen
python scripts/perception/evaluate.py --task shimen
python scripts/test.py --group 师门
```

校准中间文件保存在 `.tmp/`，正式资源只有题干与物品特征。题目、原图和真值沿用公共读取、原图映射、增强和评分；不读取标注队列或网上参考图。寻物失败及未确认拼图进入标注器，由 AGENT 先完成 AI 标注，再提交人类确认，确认后固化、校准和回归；拼图可保留会话中的明确确认依据。寻物失败时 Lua 在持久化免费重试预算内先重试绕过，等待人类标注。流程截图由 AGENT 自主核对并直接固化，不进入待标注队列。

只读观察入口为 `scripts/device/inspect-device.py`；采集所需的页面操作必须通过 Lua 状态机。识别题失败原图按任务和题目进入标注器，流程失败现场由 AGENT 自主处理。已记录机会可用 `run-daily.py --mode run --task shimen --step advance --account current --shimen-needed 2` 执行设备识物，调试时增加 `--routine-screenshots --verbose-logs` 保留点击前后画面。采集过程和评测报告保存在 `debug-runs/`。
