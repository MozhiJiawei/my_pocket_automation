# 师门

当前处于数据采集阶段，设备任务入口只观察并返回未实现，不接取任务。电脑辅助采集入口为 `scripts/device/collect-shimen.py`，只操作已核对角色的师门场景。

寻物按小游戏题目分类，不能用上层师门委托名称代替题目。同一题目下的物品差异不算新门类；拼图按完整图案归组，位置重排不算新门类。每次机会按完整十轮统计新门类，只有整批无新门类才结束；达到工具上限或异常中断均不算采集完成。

原始过程留在 `debug-runs/`，完整采集进入 `annotation-web/` 本地标注队列；用户确认并完成核对后才固化到 `testdata/师门/`。正式评测共用现有目录读取、生产识别调用、增强及评分，不读取标注队列。
