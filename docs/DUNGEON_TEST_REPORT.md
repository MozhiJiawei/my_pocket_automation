## 新界面发现与反馈闭环

旧参考代码不能直接套用：新版副本是五关总览，“开启”立即开始战斗；胜利三秒后自动续关，最终奖励页还需区分通关与花精力领取。车迟国的当前名称是“车迟斗法”，卡片需要滑动选择。

每个未识别的新状态先停下并保存截图，再提取页面特征、离线回归、发布校验哈希、恢复已有进度。最终奖励最初作为未知画面安全暂停，校准后只通过返回按钮收尾，没有花费精力。

车迟斗法运行末段出现一次电脑端状态查询通信错误。读取设备状态及本轮证据后确认脚本已暂停；没有重新开启副本。运行器现对只读状态查询重试，通信异常时仍尝试采集证据，避免把通信失败当成重新挑战的理由。
