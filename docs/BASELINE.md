# 每日自动化基线

目标：遍历人工已登录的角色，完成师门、抓鬼、乌鸡国、车迟国，再开启葫芦、签到并领取活跃度奖励。账号认证由用户完成。

## 模块划分

- `src/main.lua`、`daily.lua`：角色核对、任务调度及结果汇总。
- `src/tasks/`：师门、抓鬼、副本、收尾四类任务；识别资源跟随任务。
- `src/common/`：识别、设备操作、角色切换和导航。
- `src/dfx/`：关键状态日志、错误现场与Profile；电脑端工具见 `scripts/`。

任务通过 `run(context)` 返回 `status` 和 `reason`。未实现、暂停或失败不能冒充完成；只有确认安全返回首页后才继续其他任务。

运行期账本按角色和任务隔离，只放在 Lua 上下文内存中。启动后从游戏当前页面恢复，师门、抓鬼以明确完成卡片验收，副本通关与领奖分别确认。已核验状态在本次运行内复用，操作前后仅检查需要变化的页面与按钮，避免重复导航核验。任务不设置费用预算、不核对数字任务数量。成功退出脚本不等于业务完成。

角色配置、身份特征和凭据在仓库外；不读写持久化业务进度或重试账本。日志、截图和结果报告只供调试，不用于下一次运行恢复。业务日期使用电脑本地日期；跨游戏日界线的无人值守运行未受支持。

当前实现与已知问题见 [能力边界](STATUS.md)。目录职责以根目录 `AGENTS.md` 为准，具体入口见各模块README。
