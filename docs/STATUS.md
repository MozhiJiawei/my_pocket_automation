# 当前能力与已知问题

| 模块 | 当前实现 |
|---|---|
| 主循环 | 选择已登录角色、核对身份、按角色隔离任务进度和奖励策略。 |
| 抓鬼 | 对话、寻物、四格拼图、战斗等待及次数核对；识别范围由任务资源和正式用例限定。 |
| 副本 | 乌鸡国、车迟国连续战斗、完成核对及按授权策略领奖。 |
| 师门 | 已确认寻物数据已固化，复用抓鬼多点找色；每项首次加最多3次免费重试，次数持久化，默认跨页找齐两个答案。拼图先用旧特征尝试，失败保留现场交接标注，用户确认后固化和校准。已接入地点选择、寻物准备、抓怪、战斗、交付与结束对话；交付后核对身份和账本再领取下一项，第20次通过师门已完成卡片验证。新业务日核对角色、空闲与零次数后可建立账本；显式跨日恢复隔离两日进度并保留重试次数。免费重试分支及未见题型尚未全部设备验证，未知页面有界等待后停止；禁止电脑端代操作。 |
| 收尾 | 同角色、同业务日的师门20次、抓鬼25次及所选副本完成记录核验后，进入宝库；自动循环开启任务、副本葫芦，特殊葫芦使用“丢弃所有”，各分类显示“暂无葫芦”后返回首页。开启数量不记账，不逐个识别库存数字。师门后调试入口核对当前角色的师门完成卡片，只报告该角色宝库收尾，不报告完整每日完成。 |

抓鬼接取路径存在多接任务、突破账本预算的风险，尚未修复。次数不一致会阻塞，但不能将这一事后检查当作有效的预算保护。部分blocked返回只记录状态日志，没有自动错误截图，需补采现场。

设备识别依赖已校准布局；未知图案停止，不能把已覆盖样本的通过推广到所有页面。业务日期采用电脑日期，跨游戏日界线不属于已支持范围。

宝库葫芦收尾与副本现场“100精力破解封印”分别处理，后者沿用逐角色授权策略；封印奖励放弃后的库存去向尚未验证。宝库副本分类的非空开启分支与完整多角色日常仍须设备验收；签到和活跃度领取未接入本模块。

师门全量标注用于校准，属于已标样本回归；题目与全部已标正反例通过离线识别检查，不证明未见图标的识别能力。设备执行必须找齐要求数量并核对成功画面；完整师门的单轮成功不代表全部题型或重复运行已稳定。

师门拼图自动核对唯一题型，也支持显式单题指定：当前格子内至少三块唯一匹配后确定排列，有界交换并验证。老虎、天将、天兵、螃蟹（游戏题目为蟹将）、虾兵、白熊已使用确认真值校准并完成设备验证；其余历史资源未逐类设备验证，默认先用旧特征尝试，失败保存现场停止。

运行统计、历史状态和调测过程均在 `debug-runs/`，不作为当前能力说明。
