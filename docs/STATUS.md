# 当前能力与已知问题

| 模块 | 当前实现 |
|---|---|
| 主循环 | 支持已登录五号名单核对与轮转，选择卡片有界双向滚动，进入后核对主页身份；按角色隔离运行期进度与奖励策略。同日同身份可复用持久化完成布尔状态，任务内部进度和重试不落盘；每号完成所有所选任务后才切下一号，身份或任务失败立即停止。 |
| 抓鬼 | 对话、寻物、四格拼图、战斗等待及完成卡片核验；识别范围由任务资源和正式用例限定。 |
| 副本 | 同一控制器按每个角色的抓鬼葫芦数量，在乌鸡国、黑风山、水陆大会、车迟斗法和平顶山中选择当日范围。逐副本核对通关，按角色策略领奖。 |
| 师门 | 已接入地点选择、寻物、拼图、抓怪、战斗、交付与结束对话；按状态持续推进至同角色当天的明确完成卡片，不核对任务数量。识别失败保留现场并按本次运行的重试上限处理；未知页面有界观察后停止。 |
| 收尾 | 同角色、同业务日的师门、抓鬼完成卡片及所选副本通关状态核验后进入宝库；循环开启任务、副本葫芦，特殊分类按当前实现清理，各分类显示“暂无葫芦”后返回首页。 |

费用预算、费用预留与数字任务目标已移除；师门、抓鬼由游戏明确完成卡片验收。页面识别错误或未支持题型仍可能导致停止，离线通过不能替代设备验收。部分 blocked 返回缺少错误截图，需结合归档检查。

设备识别依赖已校准布局；未知图案停止，不能把已覆盖样本的通过推广到所有页面。业务日期采用电脑日期，跨游戏日界线不属于已支持范围。

宝库葫芦收尾与副本现场“100精力破解封印”分别处理，后者沿用逐角色授权策略；封印奖励放弃后的库存去向尚未验证。宝库副本分类的开启与完整五角色日常已完成设备验收；签到和活跃度领取未接入本模块。

师门全量标注用于校准，属于已标样本回归；题目与全部已标正反例通过离线识别检查，不证明未见图标的识别能力。设备执行必须找齐要求数量并核对成功画面；完整师门的单轮成功不代表全部题型或重复运行已稳定。

师门拼图自动核对唯一题型，也支持显式单题指定：当前格子内至少三块唯一匹配后确定排列，有界交换并验证。老虎、天将、天兵、螃蟹（游戏题目为蟹将）、虾兵、白熊、地狱战神、雨师、骨精灵、凤凰、强盗、蛟龙、巡游天神以及按外观命名的金盔少女、蓝帽少女、铠甲棕熊、绿发蝶翼少女已使用独立审核真值校准并完成设备验证；其余历史资源未逐类设备验证，默认先用旧特征尝试，失败保存现场停止。

运行统计和调测证据均在 `debug-runs/`。设备 `res/daily_completion.tsv` 保存当天的完成布尔状态，并绑定角色主页身份资源哈希。Lua 在核验游戏最终状态后写入，过期或身份不匹配时不复用。已验证原有两副本范围的完整多角色日常。按宝库数量自动选择四个或五个副本的完整多角色流程仍需设备验收。
