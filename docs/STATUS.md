# 当前能力与已知问题

| 模块 | 当前实现 |
|---|---|
| 主循环 | 选择已登录角色、核对身份、按角色隔离任务进度和奖励策略。 |
| 抓鬼 | 对话、寻物、四格拼图、战斗等待及完成卡片核验；识别范围由任务资源和正式用例限定。 |
| 副本 | 乌鸡国、车迟国连续战斗、完成核对及按授权策略领奖。 |
| 师门 | 已接入地点选择、寻物、拼图、抓怪、战斗、交付与结束对话；按状态持续推进至同角色当天的明确完成卡片，不核对任务数量。识别失败保留现场并按本次运行的重试上限处理；未知页面有界观察后停止。 |
| 收尾 | 同角色、同业务日的师门、抓鬼完成卡片及所选副本通关状态核验后进入宝库；循环开启任务、副本葫芦，特殊分类按当前实现清理，各分类显示“暂无葫芦”后返回首页。 |

费用预算、费用预留与数字任务目标已移除；师门、抓鬼由游戏明确完成卡片验收。页面识别错误或未支持题型仍可能导致停止，离线通过不能替代设备验收。部分 blocked 返回缺少错误截图，需结合归档检查。

设备识别依赖已校准布局；未知图案停止，不能把已覆盖样本的通过推广到所有页面。业务日期采用电脑日期，跨游戏日界线不属于已支持范围。

宝库葫芦收尾与副本现场“100精力破解封印”分别处理，后者沿用逐角色授权策略；封印奖励放弃后的库存去向尚未验证。宝库副本分类的非空开启分支与完整多角色日常仍须设备验收；签到和活跃度领取未接入本模块。

师门全量标注用于校准，属于已标样本回归；题目与全部已标正反例通过离线识别检查，不证明未见图标的识别能力。设备执行必须找齐要求数量并核对成功画面；完整师门的单轮成功不代表全部题型或重复运行已稳定。

师门拼图自动核对唯一题型，也支持显式单题指定：当前格子内至少三块唯一匹配后确定排列，有界交换并验证。老虎、天将、天兵、螃蟹（游戏题目为蟹将）、虾兵、白熊、地狱战神、雨师、骨精灵已使用确认真值校准并完成设备验证；其余历史资源未逐类设备验证，默认先用旧特征尝试，失败保存现场停止。

运行统计、历史状态和调测过程均在 `debug-runs/`，不作为当前能力说明。
