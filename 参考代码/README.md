# my_pocket_automation

梦幻西游口袋版自动化脚本的历史代码提取版本，作为后续适配和增量开发的基础。

## 来源与许可证

- 上游仓库：https://github.com/wanghengxn/mhxy
- 提取提交：`8b03dd6fc12531534bdf82fda10761740fd8517d`（2022-06-29，核心文件清空前的版本）。
- 保留上游 Apache-2.0 许可证，见 `LICENSE`。
- 本目录是新建的独立 Git 仓库，不包含上游 Git 历史，也未设置远程仓库。
- `SOURCE_PROVENANCE.json` 记录提取文件及校验值。

## 提取范围

保留 18 个非空 Lua 模块：主流程、账号状态、登录退出、师门、抓鬼、封妖、兵器库、葫芦处理、画面识别、寻物和拼图，以及辅助服务区识别、旧寻物实现。

不包含上游调试入口 `test.lua`、`2.txt`、宣传截图和旧 README。`account.lua` 中注释里的账号标识已替换为占位符；`my.db` 仅保留表结构，重新生成空库；`1.txt` 是代码所需的空白初始化文件。

## 运行前提

依赖触动精灵运行环境及其 `TSLib`、`ts` 模块；这些外部依赖不在本仓库中。

入口为 `main.lua`，目标 App 包名写死为 `com.netease.mhxyhtb`。大量识别和点击使用约 480×800 竖屏坐标，需要用当前游戏画面重新验证。代码通过 `userPath()/res/` 读取资源：部署时需要将 `my.db` 和 `1.txt` 放入该资源目录，再按 `account.lua` 的格式准备本地 `account.txt`。该格式为四段，以 `----` 分隔，依次为账号、密码、服务器和角色序号；真实数据不要纳入 Git。

这是源码提取基线，尚未验证当前游戏兼容性，也未修复原有缺陷。

## 已知待修复项

- `main.lua` 的师门返回值写入 `ret`，随后错误地检查 `res`。
- 师门、抓鬼开关和封妖时间配置未实际控制对应流程。
- 寻物内部循环缺少总超时。
- 任务完成与精力不足、容量受限共用完成标志。
- 午夜重复初始化及封妖跨日状态复位不完整。
- `mLog()` 的日志实现被注释。
- `Compose()` 同时承担画面识别和兜底点击。
- 兵器兑换需要人工选择装备。

建议先验证当前截图识别，再修复单账号师门闭环，随后扩展抓鬼和其他任务。
